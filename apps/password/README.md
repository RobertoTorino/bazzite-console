# PS5 Password Generator

Makes a random password of 8 or 15 characters with a capital letter, a small letter, a number and a special character, and keeps it nowhere.

The rules meet the minimum of NIST SP 800-63B and OWASP. NIST accepts 8 characters only for an account that also
has a second sign-in step, and asks for 15 characters where the password is the only step.

How to install and use it: [PS5 Password Generator in the wiki](https://robertotorino.github.io/bazzite-console/apps/password/).

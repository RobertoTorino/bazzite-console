# Upscaler Manager

PyQt6 front-end that deploys **[HelixSR](https://github.com/lonewolf0622/HelixSR)** – the FSR 3.1 drop-in
upscaler with DLSS-style neural networks – into games on a **PlayStation 5** running **Bazzite**
(Fedora Atomic / rpm-ostree), and keeps track of where it was put.

How to install and use it: [Upscaler Manager in the wiki](https://robertotorino.github.io/bazzite-console/apps/upscaler/).

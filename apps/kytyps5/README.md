# KytyPS5 Manager

KytyPS5 Manager installs [KytyPS5-Native](https://github.com/superkeka/KytyPS5-Native) on **Bazzite** running on
PlayStation 5 hardware. It installs the KytyPS5-Native release it was tried with. It checks the memory settings the
emulator asks for, and changes none of them. It finds your games and adds them to Steam. The emulator's GPU helper
is an option that you install yourself. A log keeps what the app did.

How to install and use it: [KytyPS5 Manager in the wiki](https://robertotorino.github.io/bazzite-console/apps/kytyps5/).

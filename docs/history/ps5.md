# What is the PlayStation 5?

The PlayStation 5 is the current generation's game console, on sale since November 2020. Inside: an AMD processor
with Radeon graphics, fast memory and an NVMe SSD.

There are three versions of this console. The fat launch model has 825 GB of storage and an option to add a
separate NVMe SSD. The newer slim model comes with a 1 TB NVMe SSD and has a digital-only version and a disc
version. The high-end model is the Pro: it comes with 2 TB of NVMe SSD storage and has more memory and more GPU
power.

## Linux on the PlayStation 5

Running Linux is the work of the [ps5-linux](https://github.com/ps5-linux) project: a Linux kernel with drivers for
the console's hardware. [Bazzite](bazzite.md) runs on that kernel.

## The controller and the camera

The console's accessories work on Bazzite too: [Controller](../apps/controller.md) is for the DualSense and the
DualSense Edge, and [Webcam](../apps/webcam.md) for the PS5 HD Camera and the PS4 Camera.
